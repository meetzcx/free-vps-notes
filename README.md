# 免费 VPS 笔记

个人研究笔记：记录公开的免费 VPS 套餐信息，仅供参考，以官方页面为准。

## Vyce（vyce.cloud）

- 免费档 Vps-Mini：2 GB 内存、1 核 CPU、6 GB 磁盘，完整 root 访问，SSH + 浏览器终端，公网 IPv6。
- 免费，不用绑卡，一人一台。
- 登录需要注册满 30 天的 GitHub 账号。
- 免费机每 24 小时需要去仪表盘续期一次，否则关机。
- 地区（2026-10-28 查看时）：欧洲已满，亚洲仅写付费开放，美国未开；页面无免费名额实时计数。
- 条款禁止代理、挖矿等用途；共享硬件，无正常运行时间保证，不备份。

## 已跑过的工具

- uptime-kuma（louislam/uptime-kuma）：自托管监控面板，Node 运行，本地 3001 端口可打开初始设置页。
- frp（fatedier/frp v0.71.1）：内网穿透，frps 与 frpc 均可正常输出版本号。
