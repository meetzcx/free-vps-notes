- 免费档 Vps-Mini：2 GB 内存、1 核 CPU、6 GB 磁盘，完整 root 访问，SSH + 浏览器终端，公网 IPv6。
- 免费，不用绑卡，一人一台。
- 登录需要注册满 30 天的 GitHub 账号。
- 免费机每 24 小时需要去仪表盘续期一次，否则关机。
- 地区（2026-10-28 查看时）：欧洲已满，亚洲仅写付费开放，美国未开；页面无免费名额实时计数。
